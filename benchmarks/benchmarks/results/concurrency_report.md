## Interpretation

- **N** = number of requests fired in parallel
- **Mean/p50/p95/Max** = per-request latency within the batch
- **Throughput** = requests completed per second (successful only)
- **Errors** = failed requests (timeouts, 5xx, connection errors)
- If Mean ≈ N × single-request latency, the server is serialising (no true parallelism)
- If Mean stays flat as N grows, the server handles parallel load well
